# Extraction Pass Checklist

Use this when converting source material into HSM records.

## 1. Identify source

Record:

- source id
- source type
- repo/path/URL/archive id
- date collected
- date created or period covered
- access level
- sensitivity

## 2. Preserve original boundary

Do not rewrite the source into a convenient story.

Keep separate:

- what the source literally contains
- what it implies
- what the model infers
- what remains unknown

## 3. Extract records

Possible record types:

- event
- claim
- preference
- skill
- project
- relationship
- constraint
- value
- style sample
- anchor
- affective pattern
- contradiction
- uncertainty

## 4. Label confidence

Use:

- high: direct and clear evidence
- medium: supported but incomplete
- low: weak, inferred, or partial
- unknown: not enough basis

## 5. Link evidence

Every extracted durable item needs at least one evidence reference or a clear label that it is inference/testimony.

## 6. Capture contradictions

Do not smooth contradictions away.

Record:

- what conflicts
- source ids
- date ranges
- possible explanations
- status: unresolved unless actually resolved

## 7. Promote carefully

Extraction creates candidates. Integrity checks promote candidates.

Do not skip the update gate.
