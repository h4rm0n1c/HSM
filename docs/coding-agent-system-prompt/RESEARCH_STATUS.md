## Risk Register

- **Semantic coverage without control**: a rule may be present but fail to govern action.
- **Open-loop state chaining**: do not trust an attempted result before dependent action.
- **Evidence destruction**: do not clean up artifacts still needed for diagnosis or recovery.
- **Verification theatre**: dependency-aware checks must not become ritual around trivial operations.
- **Serialization regression**: independent work remains parallel.
- **Task-abandonment regression**: pausing mutation does not end safe diagnosis.
- **Prompt bloat**: compile C43-C47 into the existing loop, not five new sermons.
- **Runtime overclaim**: static prose cannot guarantee contracts or provenance the harness lacks.
- **Safety regression**: closed-loop execution does not weaken authority, user-work, secret, or destructive-action boundaries.
